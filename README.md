# Farmer Sales Platform - Backend (Spring Boot)

This is the backend API for the Farmer Sales Platform, built with Spring Boot 3 and Java 17.

## Requirements
- Java 17
- MySQL Server
- Maven

## Setup & Run
1. Copy `.env.example` to `.env` or set the environment variables in your IDE.
2. Update the database credentials in the environment variables.
3. Run `mvn spring-boot:run`.

The API will be available at `http://localhost:8082`.
